# Aethlock

**Aethlock by AethDoesOSes**
Build 2608.05

Aethlock is a Windows management and customization tool designed to provide quick access to system tweaks, utilities, and tools in one place.

## ✨ Features

### 🔧 Available Tools

* **Activate BCPE (Bootscreen Command Prompt Exploit)**

  * Activates Command Prompt mode during boot using the required files.

* **Switch sethc.exe by cmd.exe**

  * Replaces Sticky Keys executable with Command Prompt for system customization and testing purposes.

* **Install 7-Zip**

  * Automatically downloads and installs 7-Zip.

* **Windows 7 Login Screen**
  * Currently under developement
  * Restores the Windows 7-style login experience using the required components.
  * Requires additional files.
  

* **Run as TrustedInstaller**

  * Currently under development.

* **Take Ownership Context Menu**

  * Adds or removes the "Take ownership" option from the Windows context menu.

* **Sign-up Screen Manager**

  * Currently under development.

* **God Mode**

  * Installs quick access to Windows God Mode.

* **Uninstall Microsoft Edge**

  * Removes Microsoft Edge Chromium from the system.

## 💻 Requirements

* Windows 7 or later
* Administrator privileges
* Internet connection for downloading external components

## ⚠️ Disclaimer

* Some features modify Windows files and system settings.
* Create a restore point before using tools that modify system components.
* Some features may depend on your Windows version.
* Features marked as "Under Development" are subject to change.
